# 🐭 Mouse Runner — 3D Infinite Runner

A lane-based 3D infinite runner game built in Unity, focusing on smooth procedural track generation, player movement mechanics, and dynamic obstacle and coin pattern spawning.

🎮 **[Play the Live Demo on Unity Play](https://play.unity.com/en/games/7b57862d-4b36-4bd3-9761-d1ca9042fbca/mouse-runner)**

---

### 🛠 Technical Specifications
* **Engine / Version:** Unity 6.0 (or compatible 6x version)
* **Language / Scripting:** C#
* **Target Platform:** WebGL / Standalone PC

---

### 🚀 Key Gameplay Features
* **Lane-Based Movement:** Smooth lane switching and jump mechanics.
* **Procedural Track Generation:** Continuous road spawning with dynamic scaling difficulty.
* **Structured Coin Spawning:** Custom coin patterns (straight lines and zig-zags) designed to guide player movement and signal upcoming obstacles.
* **High Score System:** Persistent score tracking to monitor player progress and run length.

---

### 🎮 How to Run Locally
1. **Clone the repository:** `git clone https://github.com/preizeinguuna/3D-game-project.git`
2. **Open in Unity:** Open the project directory using Unity Hub.
3. **Play:** Launch the main scene in `Assets/Scenes` and press **Play** in the Unity Editor.
